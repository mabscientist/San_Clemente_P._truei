# P_truei_figures
R scripts for figures for the following manuscript:

Becker MA, Bell KC, Lopez-Ortiz S, Maldonado JE, Edwards CW, Castañeda-Rico S. (2026) Genomic detection of a novel _Peromyscus truei_ invasion on San Clemente Island, California. _Therya_ 17:277-294. doi: 10.12933/therya.2026.6265
https://therya.mastozoologiamexicana.com/index.php/THERYA/article/view/6265

Figure 1 was made with P.truei_map.R
(GeoJSON file too large to upload here but available on request)

Figures 3-4 and supplemental phylogenetic trees were visualized with truei_trees.R

Figure 5 and supplemental box plots were made with measurement_boxplots.R

CSVs with measurement data are available here and as supplemental material with the manuscript: https://therya.mastozoologiamexicana.com/index.php/THERYA/article/view/6265

Raw genomic/genetic data is available on GenBank (PZ213486-PZ213497) and SRA (PRJNA1442848).
